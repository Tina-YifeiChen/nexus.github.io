# Nexus AI 智航湾区 v21

本版本基于最新国创赛项目计划书升级，核心定位为：

**Nexus AI 智航湾区——基于 Multi-Agent 协同的大湾区全周期升学决策平台**

前台表达：留学申请版高德地图。  
后台架构：背景诊断 Agent、路径规划 Agent、风险识别 Agent、努力模拟 Agent、时间导航 Agent、案例匹配 Agent、真人复核模块协同工作。

## 页面结构

- `index.html`：首页、低门槛背景输入、Multi-Agent 协同架构、时间地图、顾问入口、学校官网直达。
- `status.html`：用户点击生成后进入的申请状态页，展示画像摘要、六维路况雷达、努力变量模拟入口。
- `profile-detail.html`：画像详情，承接冲刺 / 主申 / 稳妥 / 替代路线和分享图。
- `effort.html`：努力变量模拟详情，展示语言、实习、材料、预算等变量如何改变路径。
- `timeline.html`：时间导航 Agent 详情页，展示全周期阶段任务。
- `advisors.html`：真人复核与顾问入口，嵌套案例入口。
- `advisor-profile.html`：顾问个人主页，展示可信背景、能做什么、记录、满意度和服务边界。
- `case-profile.html`：案例匹配详情，展示个人自述、经历时间线、系统分析与相似路径。

## 关键改动

1. 首页新增 Multi-Agent 协同架构解释。
2. 扫描动画改为 Agent 协同扫描语言。
3. 状态页新增 Agent 诊断过程卡片。
4. 时间地图升级为时间导航 Agent。
5. 努力模拟升级为努力变量模拟 Agent。
6. 顾问系统升级为真人复核与人机协同闭环。
7. 保留底部四导航：首页 / 状态 / 地图 / 顾问。

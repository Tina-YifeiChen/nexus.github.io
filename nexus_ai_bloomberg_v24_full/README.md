# Nexus AI 智航湾区 v24 完整代码版

本版本是“彭博社风柔和版 + 简洁主线 + Multi-Agent 协同表达”的完整前端代码包。

## 文件结构

- index.html：首页，低门槛测评入口、主线说明、Multi-Agent 架构、时间地图入口
- status.html：查看我的申请状态，展示画像摘要、六维路况雷达、努力模拟入口
- profile-detail.html：申请画像详情，展示冲刺/主申/稳妥/替代路线
- effort.html：努力方案详情，展示努力变量模拟后的行动清单
- timeline.html：申请时间地图详情，展示全周期任务与风险提醒
- advisors.html：真人复核页，展示学长学姐/顾问入口和案例嵌套
- advisor-profile.html：顾问个人主页，展示服务能力、记录、满意度和边界
- case-profile.html：完整案例页，展示个人自述、经历时间线、系统分析
- assets/css/style.css：全局视觉样式，彭博社风柔和配色
- assets/js/app.js：扫描动画、雷达图、努力模拟、底部导航激活

## 使用方法

直接打开 index.html 即可预览。部署到 GitHub Pages 时，请保持所有文件和 assets 文件夹在同一目录下。

## 风格说明

本版本不再使用原来的薄荷绿强视觉，而是采用米白底、深海军蓝、低饱和金棕强调色。页面默认只保留主线，次级内容使用 details 折叠嵌套。
